Answer sheets can bee uploaded in bulk. Two kinds of bulk-upload are supported:
  • Just uploading a bunch of files. Each of the file's names must contain the student-ID of the corresponding student.
  • Uploading a zip-archive containing a directory for each student. The directory's name must contain the student-ID.
Either way, only PDF files are supported as answer sheets.
